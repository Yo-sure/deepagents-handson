# Harness 설계 메모 안내

수업 중 작성 위치는 `notebooks/build-agent.ipynb`의 **Harness 설계 메모** 셀입니다. 이 파일에 따로 작성하지 않습니다.

교재 Harness 장의 개인 활동에 있는 기능 문제 F1과 설명 문제 D1을 읽고 다음 두 결과를 노트북에 적습니다.

1. 문제 발견 → 수정 → 기능·설명 검토 → 취합 → 종료의 실행 순서 하나
2. 중복 알림, 기대값을 바꾼 PASS, 검토 누락에 대한 다음 행동과 확인할 근거

같은 후보 버전의 결과를 확인하고, 수정 시도 2회 안에 해결하지 못했을 때 인계할 내용을 정합니다. 역할별 상세 계약은 먼저 마쳤을 때 진행하는 선택 확장입니다.
